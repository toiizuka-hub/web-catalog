# AHC サービス ウェブカタログ

電子ブックのように閲覧できるカタログサイトです。カテゴリごとにサービスを整理し、納期や標準料金などの基本情報を一覧で確認できます。フィルターと検索を組み合わせて目的のサービスを素早く探せます。

## プロジェクト構成

```
├── index.html          # 画面構造とテンプレート
├── styles.css          # レイアウト・配色・レスポンシブ設定
├── data/
│   └── services.js     # カタログに表示するカテゴリとサービスデータ
└── scripts/
    └── app.js          # データの描画、フィルター・検索処理
```

## 使い方

1. 任意のHTTPサーバーでルートディレクトリを公開します。
   ```bash
   # 例: PythonのSimpleHTTPServerを利用
   python -m http.server 8000
   ```
2. ブラウザで `http://localhost:8000` を開きます。
3. 目次やカテゴリ、検索フォームを使ってサービス情報を閲覧できます。

## 主な機能

- 目次からカテゴリやサービスへスムーズに移動
- カテゴリ・納期・料金帯フィルター
- フリーワード検索（全角・半角を正規化）
- サービスごとの詳細ポイント、タグ表示
- レスポンシブ対応デザイン

## データ更新

`data/services.js` の `catalogData` を編集することでサービス情報を追加・更新できます。`lastUpdated` の日付を変更するとページ下部に反映されます。
